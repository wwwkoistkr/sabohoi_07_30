# 사보회 골프 타수표

모바일과 PC에서 함께 사용하는 Cloudflare Workers 기반 골프 타수 관리 앱입니다.

## 운영 주소

- https://sabohoi-07-30.wwwkoistkr.workers.dev

## 표 구조

| No | 회원 이름 | 평균타수 | 날짜별 타수 | 순위 |
|---|---|---|---|---|

- 회원 이름은 한글 4자 기준이며 입력 길이도 최대 4자입니다.
- 날짜별 타수 입력은 최대 3자리입니다.
- 순위는 최대 2자리가 보이도록 좁은 열로 표시합니다.
- 평균타수는 `참가한 날짜의 타수 합계 ÷ 타수를 입력한 참가 날짜 수`로 자동 계산합니다.
- 기존 `평균금액` 자리에 계산된 평균타수를 표시하며, 오른쪽의 중복 평균 열은 제거했습니다.
- 모바일에서는 평균타수와 최근 날짜 3일이 한 화면에 들어오도록 열 너비를 최적화합니다.
- 순위는 날짜별 낮은 타수가 우선이며, 동타이면 전체 날짜 참석 횟수가 많은 회원을 우선합니다.
- 각 날짜의 `정렬` 버튼을 누르면 해당 날짜 순위대로 회원 전체 행을 정렬하고, 타수가 0인 회원은 아래로 이동합니다.

## 권한

- 일반 사용자: 회원 이름·타수를 최초 입력 후 24시간 동안 수정할 수 있습니다.
- 입력 후 24시간이 지난 회원 이름·타수는 서버에서 관리자만 수정하도록 제한합니다.
- 관리자: 회원·날짜·타수·화면 문구·이미지를 모두 관리할 수 있습니다.
- 기존 이름·번호·타수·금액·회원·날짜·이미지 삭제는 관리자 인증이 있어야 서버에서 승인됩니다.
- 관리자 비밀번호와 세션 서명 키는 Cloudflare Secret으로만 관리합니다.

## Cloudflare 분리 저장 구조

- D1 `sabohoi-07-30-data`: 정산표 상태, 버전, 로그인 실패 제한, 관리자 작업 이력
- R2 `golf-penalty-assets`: `assets/` 아래의 이미지 원본만 저장
- 기존 R2의 `sheet/data.json` 데이터가 있으면 최초 요청에서 D1으로 자동 이전합니다.

## D1 마이그레이션

```powershell
npm.cmd exec wrangler d1 migrations apply -- sabohoi-07-30-data --local
npm.cmd exec wrangler d1 migrations apply -- sabohoi-07-30-data --remote
```

## 개발과 배포

```powershell
npm.cmd run dev
npm.cmd run build
npm.cmd run deploy
```

프로젝트 상위 폴더의 `sabohoi_07_30_deploy.exe`를 실행해도 운영 배포할 수 있습니다.
